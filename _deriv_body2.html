四轨道积分：双曲线轨道

这一节把两条守恒律合成一个关于轨道的微分方程并解出它。结果会告诉我们：α 粒子在库仑场中的轨道是一条以核为一个焦点的双曲线——这个几何事实是后面一切推论的地基。

4.1  从守恒律到轨道方程

用极坐标写出能量守恒式 (3.4)。横向速度由角动量给出 v_{\varphi } = L/(mr)，径向速度写成对角的导数 v_{r} = r\dot{} = (dr/d\varphi )\varphi \dot{}，而由式 (3.6) \varphi \dot{} = L/(mr^{2})，于是

E=\frac{L^{2}}{2mr^{4}}\sqrt{\frac{dr}{d\varphi }}^{2}+\frac{L^{2}}{2mr^{2}}+\frac{C}{r} (4.1)

作代换 u \equiv 1/r。此时 1/r^{4}\,(dr/d\varphi )^{2} = (du/d\varphi )^{2}，式 (4.1) 化简为一个不含一次导数项、且没有显含 φ 的方程：

E=\frac{L^{2}}{2m}\sqrt{\frac{du}{d\varphi }}^{2}+\frac{L^{2}u^{2}}{2m}+Cu (4.2)

两边对 \varphi 求导，并约去公因子 (L^{2}/m)(du/d\varphi )（该因子在转折点处为零，需单独讨论，见附录 A），得到一个常系数线性方程：

\frac{d^{2}u}{d\varphi ^{2}}+u=-\frac{mC}{L^{2}} (4.3)

式 (4.3) 右端的负号从哪里来

负号是排斥的标记。若把力改成吸引（如电子绕核），右端变为 +mC/L^{2}，解的形式随之变为 r = \alpha /(1 + e\,\cos \,\varphi )——那才是行星轨道（椭圆/双曲线，核在焦点上）。这里 e\,\cos \,\varphi 与 1 的相对符号相反，所以轨道的凹侧背离力心：粒子被"推出去"。这个符号差异正是卢瑟福散射与行星运动在几何上的唯一区别。

4.2  解的形式：圆锥曲线

式 (4.3) 的通解为

u(\varphi )=A\,\cos \,\varphi +B\,\sin \,\varphi -\frac{mC}{L^{2}} (4.4)

由于轨道关于最近点（近核点，apsis）对称，我们可以把极角的原点选在近核点方向上，即令 \varphi = 0 处 du/d\varphi = 0。这立即给出 B = 0。近核点处 du/dφ = 0 并非额外假设，它是"轨道在近核点处 r 取极值"的直接后果。

再引入两个具有明确物理意义的量——一个长度和一个纯数：

\alpha \equiv \frac{L^{2}}{mC},\ \ e\equiv A\alpha (4.5)

于是 u = A\cos \varphi - 1/\alpha，取倒数得到轨道方程：

r(\varphi )=\frac{\alpha }{e\,\cos \,\varphi -1} (4.6)

式 (4.6) 就是极坐标下圆锥曲线的标准式，e 为偏心率。e < 1 为椭圆，e = 1 为抛物线，e > 1 为双曲线。由于粒子来自无穷远又回到无穷远，且势能在无穷远为零、动能为正，轨道必须是开放的；又由上一节的符号讨论，e > 1。因此：轨道是以核为一个焦点的双曲线。

由式 (4.6) 可直接读出两个几何特征。第一，r 在 \varphi = 0 处取极小值

r_{\text{min}}=r(0)=\frac{\alpha }{e-1} (4.7)

第二，粒子只能到达 e\,\cos \,\varphi \ge 1 的角度范围。记 \varphi _{\infty } 为 r \to \infty 时 \varphi 的极限，则

\cos \,\varphi _{\infty }=\frac{1}{e},\ \ \varphi _{\infty }=\arccos \,\frac{1}{e} (4.8)

4.3  散射角与偏心率

式 (4.6) 描述的轨道关于 \varphi = 0 对称：粒子从 \varphi = -\varphi _{\infty } 进入，经过近核点，从 \varphi = +\varphi _{\infty } 离开。现在把它翻译成实验室里的角度。

在无穷远处 v_{r} \gg v_{\varphi }，速度几乎沿径向。入射端速度指向力心，其方向角为 \pi - \varphi _{\infty }；出射端速度背离力心，方向角为 \varphi _{\infty }。两者之差就是散射角：

\theta =(\pi -\varphi _{\infty })-\varphi _{\infty }=\pi -2\varphi _{\infty }\ \ \Rightarrow \ \ \varphi _{\infty }=\frac{\pi -\theta }{2} (4.9)

代入式 (4.8) 并用 \cos ((\pi -\theta )/2) = \sin (\theta /2)：

\frac{1}{e}=\cos \,\frac{\pi -\theta }{2}=\sin \,\frac{\theta }{2}\ \ \Rightarrow \ \ e=\frac{1}{\sin (\theta /2)}=\csc \,\frac{\theta }{2} (4.10)

式 (4.10) 是一个很强的结果：偏心率只由散射角决定，与能量、电荷、瞄准距都无关。两个极限可以自检：正碰 \theta \to \pi 给出 e \to 1（双曲线退化为抛物线，粒子恰好"擦到"折返点）；擦边 \theta \to 0 给出 e \to \infty（双曲线拉直成一条直线，正如无场情形）。

五散射角与瞄准距的关系

上一节给出了轨道的形状，但还没把 \theta 与真正决定命运的参数 b 联系起来。这一节用冲量法求出这条关系，并在 5.4 用完全独立的第二条路线互校。

5.1  动量变化所受的两条约束

约束一：大小。在无穷远处势能为零，故入射与出射速率相等，均为 v_{0}。两个等长矢量 m\vec{v}_{0} 与 m\vec{v}_{0}' 夹角为 \theta，其差的模为

|\vec{\Delta p}|=2mv_{0}\,\sin \,\frac{\theta }{2} (5.1)

为什么？把等长矢量的差写成 2v\sin (\theta /2)：两个矢量 \vec{a}, \vec{b} 等长时 |\vec{a}-\vec{b}| = 2|\vec{a}|\sin (\theta /2)，其中 \theta 为夹角。这是"弦长 = 2R sin(半角)"的直接应用。

约束二：方向。轨道关于近核点与力心的连线（即对称轴）镜像对称。库仑力在镜像下不变，而垂直于对称轴的冲量分量在轨迹前半段与后半段等大反向，彼此抵消。因此净冲量严格沿对称轴，且因力为斥力而指向背离核的一侧。

5.2  把冲量积出来

设 \varphi 为粒子位置矢量与对称轴的夹角（与 4.2 节同一约定）。冲量沿对称轴的分量为

\Delta p=\int _{-\varphi _{\infty }}^{+\varphi _{\infty }}\frac{C}{r^{2}}\,\cos \,\varphi \,dt (5.2)

关键一步是用式 (3.6) 换掉 dt。这一步之所以奏效，是因为 dt = (mr^{2}/L)d\varphi 分子上的 r^{2} 恰好与力中的 1/r^{2} 相消，积分顿时变得与轨道形状无关：

\Delta p=\frac{mC}{L}\int _{-\varphi _{\infty }}^{+\varphi _{\infty }}\cos \,\varphi \,d\varphi =\frac{mC}{L}\,[\sin \,\varphi ]_{-\varphi _{\infty }}^{+\varphi _{\infty }}=\frac{2mC}{L}\,\sin \,\varphi _{\infty } (5.3)

由式 (4.9) 与 (4.10)，\sin \varphi _{\infty } = \sin ((\pi -\theta )/2) = \cos (\theta /2)，于是

\Delta p=\frac{2mC}{L}\,\cos \,\frac{\theta }{2} (5.4)

5.3  联立求解

式 (5.1) 与 (5.4) 是同一个 \Delta p 的两种表达，令其相等：

2mv_{0}\,\sin \,\frac{\theta }{2}=\frac{2mC}{L}\,\cos \,\frac{\theta }{2} (5.5)

两边约去 2m，用 L = mv_{0}b 与 E = \tfrac{1}{2}mv_{0}^{2} 整理：

v_{0}\,\sin \,\frac{\theta }{2}=\frac{C}{mv_{0}b}\,\cos \,\frac{\theta }{2}\ \ \Rightarrow \ \ mv_{0}^{2}b\,\sin \,\frac{\theta }{2}=C\,\cos \,\frac{\theta }{2} (5.6)

即 2Eb\,\sin (\theta /2) = C\,\cos (\theta /2)。于是得到本节的核心结果：

\tan \,\frac{\theta }{2}=\frac{C}{2Eb},\ \ \ b=\frac{C}{2E}\,\cot \,\frac{\theta }{2} (5.7)

式 (5.7) 里出现了贯穿全文的特征长度 C/(2E)。它完全由入射条件决定，与瞄准距无关；b 与 \theta 的关系就是这个长度充当"标尺"的 \cot 曲线。三个极限都合理：b \to \infty 时 \theta \to 0（远处掠过，几乎不偏）；b \to 0 时 \theta \to \pi（正碰，原路返回）；b 越小偏转越大，且严格单调。

5.4  第二条路线：从轨道方程直接互校

冲量法用到"净冲量沿对称轴"这一对称性论证。为了不留下任何可疑之处，这里再从轨道方程本身独立算一遍。在近核点处速度纯横向，能量守恒式 (3.4) 给出

E=\frac{L^{2}}{2mr_{\text{min}}^{2}}+\frac{C}{r_{\text{min}}} (5.8)

把 L^{2} = mC\alpha（式 4.5）与 r_{\text{min}} = \alpha /(e-1)（式 4.7）代入，消去 \alpha：

E=\frac{C}{2}\,\frac{e-1}{r_{\text{min}}}+\frac{C}{r_{\text{min}}}=\frac{C}{2r_{\text{min}}}(e+1)\ \ \Rightarrow \ \ r_{\text{min}}=\frac{C}{2E}(e+1) (5.9)

再由式 (4.5) 与 L^{2} = 2mEb^{2}：

b^{2}=\frac{L^{2}}{2mE}=\frac{C\alpha }{2E}=\frac{C}{2E}\,\frac{C(e+1)}{2E}(e-1)=\frac{C^{2}}{4E^{2}}(e^{2}-1) (5.10)

而由式 (4.10)，e^{2} - 1 = \csc ^{2}(\theta /2) - 1 = \cot ^{2}(\theta /2)（因为 1 + \cot ^{2} = \csc ^{2}）。开方即得

b=\frac{C}{2E}\,\cot \,\frac{\theta }{2} (5.11)

与式 (5.7) 完全一致。两条互不依赖的推导（一条用力的时间积分，一条用轨道几何与能量）给出同一结果，式 (5.7) 可以放心使用。

六最近逼近距离

把式 (4.10) 与 (5.9) 合起来，立刻得到最近逼近距离与散射角的关系：

r_{\text{min}}=\frac{C}{2E}\,(1+\csc \,\frac{\theta }{2})=\frac{C}{2E}\,(1+\sqrt{1+\frac{2Eb}{C}^{2}}) (6.1)

（第二个等式用了 \csc (\theta /2) = \sqrt{1 + \cot ^{2}(\theta /2)} 与式 5.7 的 \cot (\theta /2) = 2Eb/C。）

6.1  正碰距离：一个自然的长度标尺

取正碰 \theta = \pi（即 b = 0），\csc (\pi /2) = 1，式 (6.1) 给出

d\equiv r_{\text{min}}(\theta =\pi )=\frac{C}{E}=\frac{2k_{e}zZe^{2}}{mv_{0}^{2}} (6.2)

式 (6.2) 也可以由初等论证直接看出：正碰时粒子在最近点速度为零，全部动能转化为势能，\tfrac{1}{2}mv_{0}^{2} = C/d，故 d = C/E。式 (6.1) 是它的非正碰推广。

d 是核物理中最常用的长度标尺之一，称为库仑最近接近距离。它同时给出了两条信息：一是粒子在该能量下最多能靠近核多近；二是当 d 与人射粒子的德布罗意波长、或与核半径可比时，本文的经典处理需要修正（\S 13）。

到目前为止的成果清单

已经不需要任何新假设，就能写出三个可直接与实验比较的关系：

① 瞄准距与散射角 b = (C/2E)\cot (\theta /2)（式 5.7）
② 最近逼近距离 r_{\text{min}} = (C/2E)(1 + \csc (\theta /2))（式 6.1）
③ 正碰距离 d = C/E（式 6.2）

但实验并不能直接测量单个粒子的 b——入射时 b 是不可控的。实验能测的是有多少粒子被散射到某个角度附近。这就需要把式 (5.7) 翻译成截面的语言，正是下一节的内容。
