一引言：从"葡萄干布丁"到核式模型

1903 年前后，J. J. 汤姆孙提出的原子模型把正电荷看作均匀分布在整个原子球体内的"布丁"，电子则像葡萄干一样嵌在其中。这个模型能解释当时已知的许多现象，却对一件小事给出了极其强硬的预言——而正是这个预言被实验推翻了。

汤姆孙模型给出的偏转上限

设原子半径为 R，正电荷 Ze 均匀分布在球内。由高斯定理，球内半径 r 处的电场为

E(r)=k_{e}\frac{Ze\!r}{R^{3}},\ \ E_{\text{max}}=E(R)=\frac{k_{e}Ze}{R^{2}} (1.1)

α 粒子电荷为 2e。取最有利的情形——粒子沿直径穿过、且全程处于最大场强处，横向冲量为

\Delta p_{\perp }\le 2e\cdot E_{\text{max}}\cdot \frac{2R}{v}=\frac{4k_{e}Ze^{2}}{R\!v} (1.2)

入射动量 p = mv，而 mv^{2} = 2E（E 为动能），故单次穿越的最大偏转角为

\theta _{\text{max}}\approx \frac{\Delta p_{\perp }}{p}=\frac{4k_{e}Ze^{2}}{R\cdot mv^{2}}=\frac{2k_{e}Ze^{2}}{R\!E} (1.3)

代入盖革–马斯登实验的实际条件：Z = 79（金）、R \approx 1.0\times 10^{-10} m、E = 5 MeV = 8.01\times 10^{-13} J，得

\theta _{\text{max}}\approx 4.6\times 10^{-4} \text{rad}\approx 0.026^{\circ } (1.4)

也就是说，整个原子的正电荷"摊开"在 10−10 m 尺度上时，它对 α 粒子只能产生百分之几度的扰动。要累积到 90°（1.571 rad），即便假设每次碰撞都恰好取到理论上限、且全部朝同一方向叠加，也至少需要

N\ge \frac{1.571}{4.6\times 10^{-4}}\approx 3.4\times 10^{3} \text{次} (1.5)

而 3400 次独立碰撞全部取向一致的概率量级为 2^{-3400} \approx 10^{-1024}。这是一个极为宽松的上界——真实概率还要小得多。结论无可回避：汤姆孙模型无法产生哪怕一次大角度散射。

这一节说明了什么

式 (1.3) 是纯粹的量纲论证：它只用到"正电荷分布在一个尺度 R 上"这一条。因此它的反面同样成立——只要观察到任意一次大角度散射，就足以断定正电荷不是弥散的，而必定集中在一个远小于 R 的尺度内。这就是 1911 年卢瑟福提出核式模型的全部逻辑起点。

本文的目标与路线

接下来的章节不引用"卢瑟福公式"这一结论，而是从库仑力与两条守恒律出发把它重新推出来，并对每一步的物理含义作出交代。路线是：\S 2 明确假设与其失效尺度 → \S 3 写出力与守恒量 → \S 4 积分轨道方程得到双曲线 → \S 5 用冲量法求出 b-\theta 关系 → \S 6-\S 7 得到最近逼近距离与微分散射截面 → \S 8-\S 9 讨论量级与数值 → \S 10-\S 13 提取推论并划定适用边界。四个附录给出被正文略过的计算细节。

关于 A2 的常见误解

"把原子核当成点电荷"并不意味着核真的没有大小，而是说：在本文所讨论的能量范围内，粒子能靠近的最小距离远大于核半径，因此波函数/轨道从未"进入"核内部，此时点电荷假设是一个可检验的近似。一旦能量高到使 r_{\text{min}} 与核半径可比，这条假设就失效，而它的失效恰恰成为测量核半径的手段（见 \S 10.2）。

几何约定

取靶核为原点，入射方向为 +x 轴。粒子在无穷远处沿一条与 x 轴平行、垂直距离为 b 的直线运动，b 称为瞄准距（impact parameter）。出射方向与原入射方向的夹角 \theta 称为散射角。由于力是中心力，轨道必在一个过原点且含初速度的平面内，以下均在该平面内取极坐标 (r, \varphi )，原点为力心。

三相互作用与守恒律

库仑力与相互作用常数

α 粒子（电荷 ze，z = 2）与靶核（电荷 Ze）同号，相互排斥。取力心为原点，粒子所受的力沿径向朝外：

\vec{F}=\frac{1}{4\pi \varepsilon _{0}}\frac{zZe^{2}}{r^{2}}\hat{r}\equiv \frac{C}{r^{2}}\hat{r} (3.1)

其中把整个相互作用浓缩成了一个常数：

C\equiv k_{e}zZe^{2},\ \ k_{e}\equiv \frac{1}{4\pi \varepsilon _{0}}=8.9875517923\times 10^{9} \text{N}\cdot \text{m}^{2}\text{/C}^{2} (3.2)

C 的量纲是能量×长度（J·m），它同时扮演两个角色：U(r) = C/r 是势能，而 C/E 是一个长度——后文会看到，整个散射问题的所有特征长度都是 C/E 的倍数。相应的势能为

U(r)=\frac{C}{r},\ \ U(\infty )=0 (3.3)

守恒律一：机械能守恒

库仑力是保守力，且只与 r 有关，故机械能守恒。粒子从无穷远处以速度 v_{0} 入射，在无穷远处势能为零：

E=\frac{1}{2}mv_{0}^{2}=\frac{1}{2}mv^{2}+\frac{C}{r}=\text{const} (3.4)

把速度分解为径向与横向两部分 v^{2} = v_{r}^{2} + v_{\varphi }^{2}（其中 v_{\varphi } = r\varphi \dot{}），式 (3.4) 说明：粒子越靠近核，势能越大，可用的径向动能越小——这已经预示了"最近逼近距离"的存在。

守恒律二：角动量守恒

中心力对原点的力矩恒为零，故角动量 \vec{L} = m\vec{r} \times \vec{v} 守恒，方向固定（垂直于轨道平面），大小

L=m\,r^{2}\varphi \dot{} (3.5)

在无穷远处，速度垂直于瞄准距臂，故 L = mv_{0}b。于是式 (3.5) 给出一个后面反复使用的替换关系：

mv_{0}b=m\,r^{2}\varphi \dot{}\ \ \Rightarrow \ \ dt=\frac{m\,r^{2}}{L}d\varphi (3.6)

式 (3.6) 是把"对时间积分"换成"对角度积分"的钥匙。由于被积函数 mr^{2}/L 中含 r^{2}，它恰好能与库仑力的 1/r^{2} 相消——这正是库仑问题能被初等积分求解的深层原因（见附录 B）。

问题的可积性

平面内有 2 个自由度，而式 (3.4) 与 (3.5) 给出 2 个独立守恒量，因此系统完全可积，轨道可由积分封闭求出。定向到具体路径：把式 (3.4) 中的 v^{2} 用 v_{r} = r\dot{} 与 v_{\varphi } = L/(mr) 表出，得到关于 r(t) 的一阶方程；再用式 (3.6) 消去 t，即得轨道方程 r(\varphi )。下一节按这个思路直接给出结果，完整的积分过程放在附录 A。

本节小结

整个散射问题由三个量完全确定：相互作用强度 C、入射能量 E、以及瞄准距 b（隐藏在角动量 L = mv_{0}b 中）。实验中前两者是给定的，b 则是随机的——所以接下来的任务就是找出 b 与可观测的 \theta 之间的确定性关系。

四轨道积分：双曲线轨道

这一节把两条守恒律合成一个关于轨道的微分方程并解出它。结果会告诉我们：α 粒子在库仑场中的轨道是一条以核为一个焦点的双曲线——这个几何事实是后面一切推论的地基。

4.1  从守恒律到轨道方程

用极坐标写出能量守恒式 (3.4)。横向速度由角动量给出 v_{\varphi } = L/(mr)，径向速度写成对角的导数 v_{r} = r\dot{} = (dr/d\varphi )\varphi \dot{}，而由式 (3.6) \varphi \dot{} = L/(mr^{2})，于是

E=\frac{L^{2}}{2mr^{4}}\sqrt{\frac{dr}{d\varphi }}^{2}+\frac{L^{2}}{2mr^{2}}+\frac{C}{r} (4.1)

作代换 u \equiv 1/r。此时 1/r^{4}\,(dr/d\varphi )^{2} = (du/d\varphi )^{2}，式 (4.1) 化简为一个不含一次导数项、且没有显含 φ 的方程：

E=\frac{L^{2}}{2m}\sqrt{\frac{du}{d\varphi }}^{2}+\frac{L^{2}u^{2}}{2m}+Cu (4.2)

两边对 \varphi 求导，并约去公因子 (L^{2}/m)(du/d\varphi )（该因子在转折点处为零，需单独讨论，见附录 A），得到一个常系数线性方程：

\frac{d^{2}u}{d\varphi ^{2}}+u=-\frac{mC}{L^{2}} (4.3)

式 (4.3) 右端的负号从哪里来

负号是排斥的标记。若把力改成吸引（如电子绕核），右端变为 +mC/L^{2}，解的形式随之变为 r = \alpha /(1 + e\,\cos \,\varphi )——那才是行星轨道（椭圆/双曲线，核在焦点上）。这里 e\,\cos \,\varphi 与 1 的相对符号相反，所以轨道的凹侧背离力心：粒子被"推出去"。这个符号差异正是卢瑟福散射与行星运动在几何上的唯一区别。

4.2  解的形式：圆锥曲线

式 (4.3) 的通解为

u(\varphi )=A\,\cos \,\varphi +B\,\sin \,\varphi -\frac{mC}{L^{2}} (4.4)

由于轨道关于最近点（近核点，apsis）对称，我们可以把极角的原点选在近核点方向上，即令 \varphi = 0 处 du/d\varphi = 0。这立即给出 B = 0。近核点处 du/dφ = 0 并非额外假设，它是"轨道在近核点处 r 取极值"的直接后果。

再引入两个具有明确物理意义的量——一个长度和一个纯数：

\alpha \equiv \frac{L^{2}}{mC},\ \ e\equiv A\alpha (4.5)

于是 u = A\cos \varphi - 1/\alpha，取倒数得到轨道方程：

r(\varphi )=\frac{\alpha }{e\,\cos \,\varphi -1} (4.6)

式 (4.6) 就是极坐标下圆锥曲线的标准式，e 为偏心率。e < 1 为椭圆，e = 1 为抛物线，e > 1 为双曲线。由于粒子来自无穷远又回到无穷远，且势能在无穷远为零、动能为正，轨道必须是开放的；又由上一节的符号讨论，e > 1。因此：轨道是以核为一个焦点的双曲线。

由式 (4.6) 可直接读出两个几何特征。第一，r 在 \varphi = 0 处取极小值

r_{\text{min}}=r(0)=\frac{\alpha }{e-1} (4.7)

第二，粒子只能到达 e\,\cos \,\varphi \ge 1 的角度范围。记 \varphi _{\infty } 为 r \to \infty 时 \varphi 的极限，则

\cos \,\varphi _{\infty }=\frac{1}{e},\ \ \varphi _{\infty }=\arccos \,\frac{1}{e} (4.8)

4.3  散射角与偏心率

式 (4.6) 描述的轨道关于 \varphi = 0 对称：粒子从 \varphi = -\varphi _{\infty } 进入，经过近核点，从 \varphi = +\varphi _{\infty } 离开。现在把它翻译成实验室里的角度。

在无穷远处 v_{r} \gg v_{\varphi }，速度几乎沿径向。入射端速度指向力心，其方向角为 \pi - \varphi _{\infty }；出射端速度背离力心，方向角为 \varphi _{\infty }。两者之差就是散射角：

\theta =(\pi -\varphi _{\infty })-\varphi _{\infty }=\pi -2\varphi _{\infty }\ \ \Rightarrow \ \ \varphi _{\infty }=\frac{\pi -\theta }{2} (4.9)

代入式 (4.8) 并用 \cos ((\pi -\theta )/2) = \sin (\theta /2)：

\frac{1}{e}=\cos \,\frac{\pi -\theta }{2}=\sin \,\frac{\theta }{2}\ \ \Rightarrow \ \ e=\frac{1}{\sin (\theta /2)}=\csc \,\frac{\theta }{2} (4.10)

式 (4.10) 是一个很强的结果：偏心率只由散射角决定，与能量、电荷、瞄准距都无关。两个极限可以自检：正碰 \theta \to \pi 给出 e \to 1（双曲线退化为抛物线，粒子恰好"擦到"折返点）；擦边 \theta \to 0 给出 e \to \infty（双曲线拉直成一条直线，正如无场情形）。

五散射角与瞄准距的关系

上一节给出了轨道的形状，但还没把 \theta 与真正决定命运的参数 b 联系起来。这一节用冲量法求出这条关系，并在 5.4 用完全独立的第二条路线互校。

5.1  动量变化所受的两条约束

约束一：大小。在无穷远处势能为零，故入射与出射速率相等，均为 v_{0}。两个等长矢量 m\vec{v}_{0} 与 m\vec{v}_{0}' 夹角为 \theta，其差的模为

|\vec{\Delta p}|=2mv_{0}\,\sin \,\frac{\theta }{2} (5.1)

为什么？把等长矢量的差写成 2v\sin (\theta /2)：两个矢量 \vec{a}, \vec{b} 等长时 |\vec{a}-\vec{b}| = 2|\vec{a}|\sin (\theta /2)，其中 \theta 为夹角。这是"弦长 = 2R sin(半角)"的直接应用。

约束二：方向。轨道关于近核点与力心的连线（即对称轴）镜像对称。库仑力在镜像下不变，而垂直于对称轴的冲量分量在轨迹前半段与后半段等大反向，彼此抵消。因此净冲量严格沿对称轴，且因力为斥力而指向背离核的一侧。

5.2  把冲量积出来

设 \varphi 为粒子位置矢量与对称轴的夹角（与 4.2 节同一约定）。冲量沿对称轴的分量为

\Delta p=\int _{-\varphi _{\infty }}^{+\varphi _{\infty }}\frac{C}{r^{2}}\,\cos \,\varphi \,dt (5.2)

关键一步是用式 (3.6) 换掉 dt。这一步之所以奏效，是因为 dt = (mr^{2}/L)d\varphi 分子上的 r^{2} 恰好与力中的 1/r^{2} 相消，积分顿时变得与轨道形状无关：

\Delta p=\frac{mC}{L}\int _{-\varphi _{\infty }}^{+\varphi _{\infty }}\cos \,\varphi \,d\varphi =\frac{mC}{L}\,[\sin \,\varphi ]_{-\varphi _{\infty }}^{+\varphi _{\infty }}=\frac{2mC}{L}\,\sin \,\varphi _{\infty } (5.3)

由式 (4.9) 与 (4.10)，\sin \varphi _{\infty } = \sin ((\pi -\theta )/2) = \cos (\theta /2)，于是

\Delta p=\frac{2mC}{L}\,\cos \,\frac{\theta }{2} (5.4)

5.3  联立求解

式 (5.1) 与 (5.4) 是同一个 \Delta p 的两种表达，令其相等：

2mv_{0}\,\sin \,\frac{\theta }{2}=\frac{2mC}{L}\,\cos \,\frac{\theta }{2} (5.5)

两边约去 2m，用 L = mv_{0}b 与 E = \tfrac{1}{2}mv_{0}^{2} 整理：

v_{0}\,\sin \,\frac{\theta }{2}=\frac{C}{mv_{0}b}\,\cos \,\frac{\theta }{2}\ \ \Rightarrow \ \ mv_{0}^{2}b\,\sin \,\frac{\theta }{2}=C\,\cos \,\frac{\theta }{2} (5.6)

即 2Eb\,\sin (\theta /2) = C\,\cos (\theta /2)。于是得到本节的核心结果：

\tan \,\frac{\theta }{2}=\frac{C}{2Eb},\ \ \ b=\frac{C}{2E}\,\cot \,\frac{\theta }{2} (5.7)

式 (5.7) 里出现了贯穿全文的特征长度 C/(2E)。它完全由入射条件决定，与瞄准距无关；b 与 \theta 的关系就是这个长度充当"标尺"的 \cot 曲线。三个极限都合理：b \to \infty 时 \theta \to 0（远处掠过，几乎不偏）；b \to 0 时 \theta \to \pi（正碰，原路返回）；b 越小偏转越大，且严格单调。

5.4  第二条路线：从轨道方程直接互校

冲量法用到"净冲量沿对称轴"这一对称性论证。为了不留下任何可疑之处，这里再从轨道方程本身独立算一遍。在近核点处速度纯横向，能量守恒式 (3.4) 给出

E=\frac{L^{2}}{2mr_{\text{min}}^{2}}+\frac{C}{r_{\text{min}}} (5.8)

把 L^{2} = mC\alpha（式 4.5）与 r_{\text{min}} = \alpha /(e-1)（式 4.7）代入，消去 \alpha：

E=\frac{C}{2}\,\frac{e-1}{r_{\text{min}}}+\frac{C}{r_{\text{min}}}=\frac{C}{2r_{\text{min}}}(e+1)\ \ \Rightarrow \ \ r_{\text{min}}=\frac{C}{2E}(e+1) (5.9)

再由式 (4.5) 与 L^{2} = 2mEb^{2}：

b^{2}=\frac{L^{2}}{2mE}=\frac{C\alpha }{2E}=\frac{C}{2E}\,\frac{C(e+1)}{2E}(e-1)=\frac{C^{2}}{4E^{2}}(e^{2}-1) (5.10)

而由式 (4.10)，e^{2} - 1 = \csc ^{2}(\theta /2) - 1 = \cot ^{2}(\theta /2)（因为 1 + \cot ^{2} = \csc ^{2}）。开方即得

b=\frac{C}{2E}\,\cot \,\frac{\theta }{2} (5.11)

与式 (5.7) 完全一致。两条互不依赖的推导（一条用力的时间积分，一条用轨道几何与能量）给出同一结果，式 (5.7) 可以放心使用。

六最近逼近距离

把式 (4.10) 与 (5.9) 合起来，立刻得到最近逼近距离与散射角的关系：

r_{\text{min}}=\frac{C}{2E}\,(1+\csc \,\frac{\theta }{2})=\frac{C}{2E}\,(1+\sqrt{1+\frac{2Eb}{C}^{2}}) (6.1)

（第二个等式用了 \csc (\theta /2) = \sqrt{1 + \cot ^{2}(\theta /2)} 与式 5.7 的 \cot (\theta /2) = 2Eb/C。）

6.1  正碰距离：一个自然的长度标尺

取正碰 \theta = \pi（即 b = 0），\csc (\pi /2) = 1，式 (6.1) 给出

d\equiv r_{\text{min}}(\theta =\pi )=\frac{C}{E}=\frac{2k_{e}zZe^{2}}{mv_{0}^{2}} (6.2)

式 (6.2) 也可以由初等论证直接看出：正碰时粒子在最近点速度为零，全部动能转化为势能，\tfrac{1}{2}mv_{0}^{2} = C/d，故 d = C/E。式 (6.1) 是它的非正碰推广。

d 是核物理中最常用的长度标尺之一，称为库仑最近接近距离。它同时给出了两条信息：一是粒子在该能量下最多能靠近核多近；二是当 d 与人射粒子的德布罗意波长、或与核半径可比时，本文的经典处理需要修正（\S 13）。

到目前为止的成果清单

已经不需要任何新假设，就能写出三个可直接与实验比较的关系：

① 瞄准距与散射角 b = (C/2E)\cot (\theta /2)（式 5.7）
② 最近逼近距离 r_{\text{min}} = (C/2E)(1 + \csc (\theta /2))（式 6.1）
③ 正碰距离 d = C/E（式 6.2）

但实验并不能直接测量单个粒子的 b——入射时 b 是不可控的。实验能测的是有多少粒子被散射到某个角度附近。这就需要把式 (5.7) 翻译成截面的语言，正是下一节的内容。

七微分散射截面与卢瑟福公式

实验中不能控制单个粒子的瞄准距，只能统计"多少粒子被弹到了哪个角度"。截面就是把"b(\theta ) 这条确定性关系"翻译成"可测量的计数分布"的桥梁。这一节完成这个翻译，并得到本文的主角——卢瑟福公式。

7.1  截面的定义

设有一束强度为 I（单位时间穿过单位面积的粒子数）的平行粒子流射向一个靶核。由于轴对称，瞄准距在 [b, b+db] 内的粒子落在面积为 d\sigma = 2\pi b\,|db| 的圆环内。把

d\sigma \equiv \frac{dN}{I}=2\pi b\,|db| (7.1)

称为微分截面。它是对单个靶核而言的等效面积，量纲为面积。d\sigma 是"落在 [\theta , \theta +d\theta ] 环内"的截面。习惯上再除以该环对应的立体角

d\Omega =2\pi \,\sin \,\theta \,d\theta (7.2)

得到与探测器立体角无关的量

\frac{d\sigma }{d\Omega }=\frac{b}{\sin \,\theta }\,|\frac{db}{d\theta }| (7.3)

截面的物理读法。截面不是几何面积，而是"有效靶面积"。它把"粒子被弹到 \theta 附近"这件事折算成"靶核在这条路径上占据了多大一块面积"。这样不同实验的几何布置就可以互相比对。

7.2  代入 b(θ) 并化简

由式 (5.7)，b = (C/2E)\cot (\theta /2)。对 \theta 求导（注意 (\cot x)' = -\csc ^{2}x）：

\frac{db}{d\theta }=\frac{C}{2E}\cdot (-\frac{1}{2})\,\csc ^{2}\,\frac{\theta }{2}=-\frac{C}{4E}\,\csc ^{2}\,\frac{\theta }{2} (7.4)

把 b、|db/d\theta | 与 \sin \theta = 2\sin (\theta /2)\cos (\theta /2) 一并代入式 (7.3)：

\frac{d\sigma }{d\Omega }=\frac{C}{2E}\frac{\cot (\theta /2)}{2\sin (\theta /2)\cos (\theta /2)}\cdot \frac{C}{4E}\csc ^{2}\,\frac{\theta }{2} (7.5)

这里发生了一次漂亮的连锁相消。记 s \equiv \sin (\theta /2)、c \equiv \cos (\theta /2)，则 \cot (\theta /2) = c/s，式 (7.5) 中三角函数因子为

\frac{c/s}{2sc}\cdot \frac{1}{s^{2}}=\frac{1}{2s^{2}}\cdot \frac{1}{s^{2}}=\frac{1}{2\sin ^{4}(\theta /2)} (7.6)

把 c 完全约掉，只剩一个纯粹的 \sin ^{4}(\theta /2)。系数为 (C/2E)(C/4E) = C^{2}/(8E^{2})，再乘上式 (7.6) 中的 \tfrac{1}{2}：

\frac{d\sigma }{d\Omega }=\frac{C^{2}}{16E^{2}}\,\frac{1}{\sin ^{4}(\theta /2)} (7.7)

最后把 C = k_{e}zZe^{2}（式 3.2）代回系数：C^{2}/(16E^{2}) = (k_{e}zZe^{2}/4E)^{2}。得到卢瑟福散射公式：

\frac{d\sigma }{d\Omega }=(\frac{k_{e}zZe^{2}}{4E})^{2}\,\frac{1}{\sin ^{4}(\theta /2)} (7.8)

若把入射粒子电荷写成 z = 2（α 粒子），靶核电荷 Z，并用 E 表示入射动能，则式 (7.8) 亦可写作 (k_{e}zZe^{2}/4E)^{2}\csc ^{4}(\theta /2) 或 (C/4E)^{2}\csc ^{4}(\theta /2)。三者完全等价。

八积分截面与大角度稀有性

8.1  散射到 θ ≥ θ0 的总截面

把式 (7.8) 对角度积分，得到"散射角超过 \theta _{0}"的截面。有一个更省力的等价做法：所有 b \le b(\theta _{0}) 的粒子都会被弹到 \theta \ge \theta _{0}，所以这个截面就是半径为 b(\theta _{0}) 的圆盘面积：

\sigma (\theta \ge \theta _{0})=\pi \,b(\theta _{0})^{2}=\pi (\frac{C}{2E})^{2}\,\cot ^{2}\,\frac{\theta _{0}}{2} (8.1)

直接对式 (7.8) 积分可以验证这一点：\int _{\theta _{0}}^{\pi }(C^{2}/16E^{2})\csc ^{4}(\theta /2)\,2\pi \sin \theta \,d\theta = \pi (C/2E)^{2}\cot ^{2}(\theta _{0}/2)。用 u = \theta /2 换元后，被积函数化为 -\text{d}(1/(2\sin ^{2}u))，积分是初等的。结果与"圆盘面积"论证一致。这也从侧面确认式 (7.8) 的归一化是正确的。

约四千万分之一。这就是为什么盖革和马斯登需要观察数以万计的闪烁、才能记录到寥寥几次大角度事件——也正是这寥寥几次，否定了汤姆孙模型。

十推论一：原子核的存在与核半径上限

推导到这里，公式本身已经完备。但物理学的价值在于它允许我们断言什么。这一节从式 (7.8) 出发，提取出三条互相独立、且都能被实验检验的结论。

10.1  正电荷必定高度集中

把 \S 1 的论证反过来用。式 (1.3) 是给定弥散尺度 R 时偏转的上界，它是一个严格的不等式。既然实验确实观测到了 \theta \ge 90^\circ = \pi /2，就必有

\frac{2k_{e}Ze^{2}}{R\,E}\ge \frac{\pi }{2}\ \ \Rightarrow \ \ R\le \frac{4k_{e}Ze^{2}}{\pi E} (10.1)

代入 5 MeV / 金的条件：

R\le \frac{4\cdot 1.822\times 10^{-26}}{\pi \cdot 8.011\times 10^{-13}} \text{m}\approx 2.9\times 10^{-14} \text{m}=29 \text{fm} (10.2)

而原子的尺度是 \approx 10^{-10} m。也就是说，集中正电荷的尺度至多是原子的 1/3400。这条结论只用到"存在 90° 散射"这一个实验事实，不依赖卢瑟福公式的具体形状，因此格外可靠。

电子不可能造成大角度散射——一个常被忽略的关键论证

有人会想：也许把 α 粒子弹回来的是电子？这个想法可以被一个纯粹的运动学事实排除。对于"质量 m 的粒子弹性撞击静止的质量 M 的粒子"，当 M < m 时，入射粒子在实验室系中的偏转角有严格上界

\sin \,\theta _{\text{max}}=M/m。对电子与 α 粒子：m_{e}/m_{\alpha } = 0.0005486/4.0015 = 1.37\times 10^{-4}，故

\theta _{\text{max}} = \arcsin (1.37\times 10^{-4}) \approx 0.0079^\circ。即便 α 粒子正面撞上一个电子，它最多只能被偏转百分之八度。要累积到 90° 需要约 11400 次方向完全一致的碰撞。因此大角度散射体必须是既重又集中的正电荷——它只能是原子核。

10.2  核半径的定量上限

式 (10.2) 给出的 29 fm 太宽松。利用卢瑟福公式本身，可以得到一个紧得多的界。

推导卢瑟福公式时用了假设 A2（点电荷）。这条假设在 r_{\text{min}} \gg R 时成立；一旦粒子能进入到核表面以内，势就不再是纯 1/r，公式必定失效。由式 (6.2)，正碰时的最近距离为 d = C/E，因此公式成立的条件可以写成一个能量条件：

\frac{C}{E}\gg R\ \ \Leftrightarrow \ \ E\ll \frac{C}{R}\equiv E_{\text{crit}} (10.3)

于是核半径可以由实验直接读出：找到卢瑟福公式开始系统失效的能量 E_{\text{crit}}，则 R \approx C/E_{\text{crit}}。α 粒子在金箔上的实测偏离出现在 E_{\text{crit}} \approx 25-30 MeV（\S 9.2 式 9.2 的理论预言是 32.6 MeV），代入得

R_{\text{Au}}\approx \frac{3.644\times 10^{-26}}{27\cdot 1.602\times 10^{-13}} \text{m}\approx 8.4\times 10^{-15} \text{m}=8.4 \text{fm} (10.4)

而由质量数经验公式 R = r_{0}A^{1/3}（r_{0} \approx 1.2 fm）算得 R_{\text{Au}} \approx 7.0 fm。两种完全独立的途径给出同一量级——这正是核式模型最有力的自洽性证据。

推论一总结

① 正电荷集中尺度 \le 29 fm（仅用"存在 90° 散射"，不依赖公式形状）
② 大角度散射体必须是重粒子（电子在运动学上被排除）
③ 核半径 \approx 8 fm 量级，与 r_{0}A^{1/3} 独立吻合

11.1  公式给出的不是一条曲线，而是三条可分别验证的标度律

11.2  为什么"核式"是不可回避的

把 \S 10 与本节合起来看，逻辑链条是封闭的：

第一步（存在性）：大角度散射被观测到 → 存在一个尺度 \lesssim 10^{-14} m 的强场区域。
第二步（成分）：该区域在运动学上不可能是电子（\S 10.1）→ 它是正电荷。
第三步（荷量）：散射强度按 Z^{2} 标度，且 Z 与元素序数吻合 → 集中的正电荷恰好携带 Ze。
第四步（排他）：原子整体电中性 → 剩下 Z 个电子必然处在这个小区域之外，占据整个原子的尺度。

这四步之后，"正电荷弥散、电子嵌在其中"的图像已无立足之地。剩下的唯一可能是：原子由一个极小的重核与核外电子云构成——即核式模型。

11.3  散射实验作为"探针"的范式意义

卢瑟福散射更深层的贡献，是确立了粒子物理最基本的方法论：用已知的探针去撞未知的靶，通过散射角分布反推靶的结构。式 (7.8) 就是这个反演的显式公式——测得 d\sigma /d\Omega，就能定出相互作用势的形式与作用区域的尺度。此后从深度非弹性散射发现夸克、到在 LHC 上确认希格斯玻色子，用的都是同一套逻辑。

十二推论三：经典模型的困难

核式模型解决了大角度散射，却立刻制造了一个更严重的危机。这一节给出这个危机的定量形式——它不属于卢瑟福散射本身，而是"把核式模型继续当作经典行星系"的必然后果。

12.1  加速电荷必然辐射

按经典电动力学，任何作加速运动的电荷都会辐射电磁波，功率由拉莫尔公式给出

P=\frac{q^{2}a^{2}}{6\pi \varepsilon _{0}c^{3}} (12.1)

核外电子在圆轨道上运动时加速度 a = v^{2}/r = k_{e}Ze^{2}/(m_{e}r^{2})，而轨道能量 E = -k_{e}Ze^{2}/(2r)。把 dE/dt = -P 写成对 r 的方程并积分（从玻尔半径 a_{0} 一直落到 r = 0），得到塌缩时间

\tau =\frac{a_{0}^{3}c^{3}m_{e}^{2}}{4k_{e}^{2}Ze^{4}} (12.2)

对氢原子（Z = 1，a_{0} = 5.2918\times 10^{-11} m）代入数值：

\tau \approx 1.6\times 10^{-11} \text{s} (12.3)

约 16 皮秒。也就是说，如果电子真的像行星一样绕核作经典轨道运动，原子会在不到一亿分之一秒内辐射掉全部能量、电子坠入核中。物质根本不可能稳定存在。

这个矛盾不否定卢瑟福散射

必须把两件事分清楚。卢瑟福散射本身不受这个问题影响：α 粒子是外来闯入者，它在核附近沿着一条双曲线掠过就离去，不构成束缚轨道，因此不存在"辐射塌缩"。式 (12.1)–(12.3) 针对的是束缚电子。

真正的教训是：核式模型必然要求一套非经典的运动规律来处理束缚态。这个要求直接催生了玻尔的定态与量子化条件 L = n\hbar（1913），并最终发展成量子力学。因此，α 散射实验同时扮演了两个角色：它建立了核式模型，又证伪了经典力学在原子尺度上的适用性。

十三适用边界与各类修正

卢瑟福公式是一个精确的经典结果，但它的成立有明确的条件。以下逐条给出"何时需要修正、如何修正、量级多大"。这些边界本身就是物理信息。

13.1  反冲：把靶核质量视为有限的后果

假设 A1 把靶核当作固定不动的。实际上靶核会反冲，正确的做法是转到质心系并引入约化质量

\mu =\frac{mM}{m+M} (13.1)

质心系中相互作用能只依赖相对坐标，因此只要把 m 换成 \mu、E 换成质心系动能 E_{\text{cm}} = \tfrac{1}{2}\mu v_{\text{rel}}^{2}，式 (7.8) 的形式完全不变，只是其中的 \theta 变成质心系散射角。实验室系角度需再由附录 C 的关系转换。

13.2  电子屏蔽：把长程库仑势切断

真实原子中核外电子会部分中和核的电场。在半径 r \gtrsim a 之外，有效势被指数压低：

U(r)\approx \frac{C}{r}\,e^{-r/a},\ \ a\approx a_{0}Z^{-1/3} (13.2)

对金：a \approx 5.2918\times 10^{-11}/79^{1/3} \approx 1.23\times 10^{-11} m（约 12.3 pm）。屏蔽只在瞄准距 b \gtrsim a 时才有影响，对应

\cot \,\frac{\theta }{2}=\frac{a}{C/2E}=\frac{1.23\times 10^{-11}}{2.275\times 10^{-14}}=541\ \ \Rightarrow \ \ \theta \approx 0.21^{\circ } (13.3)

因此只要 \theta \gtrsim 1^\circ，屏蔽完全可忽略，卢瑟福公式按原样使用即可。屏蔽只在极小角度（\theta \lesssim 0.2^\circ）才起作用，而且它恰好截断了式 (8.1) 中 \theta _{0} \to 0 时的发散（\S 8.2）。

13.3  相对论修正

假设 A4 要求 v \ll c。α 粒子静能 m_{\alpha }c^{2} = 3727.4 MeV，故

\frac{v}{c}=\sqrt{\frac{2E}{m_{\alpha }c^{2}}}:\ \ 5 \text{MeV}\to 0.052,\ \ 100 \text{MeV}\to 0.232 (13.4)

5 MeV 时 v^{2}/c^{2} \approx 2.7\times 10^{-3}，非相对论近似误差约 0.3%，完全可忽略。到 100 MeV 时 v^{2}/c^{2} \approx 5.4%，必须改用相对论运动学（Mott 散射）。由于 α 粒子与多数偶偶核自旋均为 0，自旋相关的 Mott 项不出现，主要修正来自运动学。

13.4  自旋与磁相互作用

本文只考虑库仑（电）相互作用。若入射粒子或靶核有自旋，还会出现磁矩之间的相互作用。其相对大小约为 O(v^{2}/c^{2})，对 5 MeV 的 α 粒子是 10^{-3} 量级，属于可忽略的高阶效应。α 粒子自旋为 0，因此在 α 散射中这一项完全不存在。

13.5  量子力学为什么给出同一结果

这是一个容易被含糊带过的要点，值得说清楚。

在量子力学中，"瞄准距 b"不是一个可观测的轨迹参数，粒子的位置与动量不能同时确定，b 与 \theta 之间不存在一一对应。然而对纯库仑势，用玻恩近似（乃至精确解）算出的微分散射截面，在非相对论、无自旋条件下与式 (7.8) 逐字相同。

这是库仑势的特权，不是普遍规律

经典与量子结果相同，是 1/r 势的特殊性质（与库仑问题额外隐藏的 \mathrm{SO}(4) 对称性有关）。一旦势偏离 1/r：

• 加上屏蔽（式 13.2）→ 量子截面出现干涉结构，经典图像失效；
• 进入核力作用范围 → 出现衍射式的振荡，且截面不再由 Z^{2} 唯一决定；
• 能量高到 \lambda _{\text{de Broglie}} 与核尺度可比 → 必须用量子散射理论。

所以 "经典推导得到正确公式"不是方法的胜利，而是这个特定势的巧合。这一点在把卢瑟福散射作为方法论推广时必须牢记。

13.6  单次散射与薄靶条件

假设 A5 要求粒子在穿过箔时只发生一次有效散射。这条假设的检验方式很直接：散射计数必须严格正比于箔厚（表 6 第二行）。若观察到非线性（偏薄时正比、偏厚时增长更快），说明多次散射开始贡献。多次散射的角分布近似为高斯型，会叠加在卢瑟福的 \csc ^{4} 尾巴上，在小角度处首先造成偏离。

全文结论

从库仑力与两条守恒律出发，我们得到了式 (7.8) 这个闭合结果，并从中提取出三层推论：结构上——原子的正电荷集中于 \lesssim 10^{-14} m 的核内，尺度与 r_{0}A^{1/3} 自洽；方法上——散射角分布可以作为反推相互作用势与作用区域尺度的显式工具；边界上——公式在 5 MeV、重靶条件下精确成立，其失效点（\approx 30 MeV）本身又成为测量核半径的探针。而经典行星模型的崩溃（\S 12）则表明：核式模型必须配上一套新的运动学——这正是量子力学登场的地方。

附录 ABinet 方程与圆锥曲线解

正文 4.1 节从"能量守恒 + 角动量守恒"直接得到了式 (4.3)。这里用更标准的 Binet 方程独立导出同一个方程，以确认式 (4.3) 的可靠性。

径向运动方程为

m(r\ddot{}-r\varphi \dot{}^{2})=F_{r}=\frac{C}{r^{2}} (A.1)

由式 (3.6) \varphi \dot{} = L/(mr^{2})，对时间求导可把 d/dt 换成 (L/(mr^{2}))d/d\varphi。记 u = 1/r，有

r\ddot{}=-\frac{L^{2}u^{2}}{m^{2}}\frac{d^{2}u}{d\varphi ^{2}},\ \ r\varphi \dot{}^{2}=\frac{L^{2}u^{3}}{m^{2}} (A.2)

代入式 (A.1) 并整理，即得式 (4.3)：u'' + u = -mC/L^{2}。两条路线给出同一方程。

关于求导时约去的因子。两边对 \varphi 求导时约去了 du/d\varphi。若 du/d\varphi = 0 恒成立，则 u 为常数，对应圆轨道——对开放轨道（双曲线）不适用，故本文情形下该因子的零点只是孤立点（近核点），不影响解的一般性。

A.1  由解反推 A 与 α 的物理意义

把解 u = A\cos \varphi - 1/\alpha 代回能量守恒式 (4.2)，可用 \varphi = 0 处（近核点，du/d\varphi = 0）的值定出 A，从而确认 \alpha = L^{2}/(mC) 与 e = A\alpha 的定义（式 4.5）是自洽的。正文 5.4 节用这套关系做了独立互校，结果与冲量法完全一致。

附录 B冲量积分的严格计算

正文 5.2 节把积分从 -\varphi _{\infty } 到 +\varphi _{\infty } 写成了一次性积分。这里补上"为什么可以这样写"以及被积函数为何与轨道形状无关。

冲量的定义是 \Delta \vec{p} = \int \vec{F}\,dt。力的方向沿 \hat{r}。由对称性，我们只需它的对称轴分量，即把 \vec{F} 投影到对称轴方向，得到 (C/r^{2})\cos \varphi。

换元时用的关键是式 (3.6)：

dt=\frac{mr^{2}}{L}d\varphi \ \ \Rightarrow \ \ \frac{C}{r^{2}}dt=\frac{mC}{L}d\varphi (B.1)

注意右端不再含 r。这正是库仑问题可积的核心：1/r^{2} 的力与 r^{2} 的角动量因子恰好互为倒数。于是

\Delta p=\frac{mC}{L}\int _{-\varphi _{\infty }}^{\varphi _{\infty }}\cos \,\varphi \,d\varphi =\frac{2mC}{L}\sin \,\varphi _{\infty } (B.2)

一个值得注意的地方：式 (B.2) 中不含偏心率 e，也不含 \alpha——积分的值只依赖积分限 \varphi _{\infty }。也就是说，无论轨道"张得多开"，冲量都相同。这是 1/r^{2} 力的另一项特殊性质，也是为什么式 (5.7) 会如此简洁。

由式 (4.9) \varphi _{\infty } = (\pi -\theta )/2，得 \sin \varphi _{\infty } = \cos (\theta /2)，即式 (5.4)。

附录 C质心系与实验室系的转换

式 (7.8) 中的 \theta 严格来说是质心系散射角。实验在实验室系进行，两者需要通过运动学换算。设入射粒子质量 m、靶核质量 M，记质量比 \rho = m/M。

质心系中两粒子动量大小相等方向相反，散射后仍如此。把质心速度变换回实验室系，可得

\tan \,\theta _{\text{lab}}=\frac{\sin \,\theta _{\text{cm}}}{\rho +\cos \,\theta _{\text{cm}}} (C.1)

当 \rho \ll 1（重靶）时 \theta _{\text{lab}} \approx \theta _{\text{cm}}，这正是假设 A1 的精确含义。对 α + Au，\rho = 4.0015/197 \approx 0.0203，两系角度差异在 1^\circ 量级，属于可修正的系统效应。

相应地，能量也需换算：

E_{\text{cm}}=\frac{M}{m+M}E_{\text{lab}}=\frac{1}{1+\rho }E_{\text{lab}} (C.2)

把式 (7.8) 用在实验数据上时，必须用 E_{\text{cm}} 与 \theta _{\text{cm}}。对 α + Au 这带来约 2% 的能量修正，与表 7 的反冲修正一致（两者是同一件事的两种表述）。
