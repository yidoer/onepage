一引言：从"葡萄干布丁"到核式模型

1903 年前后，J. J. 汤姆孙提出的原子模型把正电荷看作均匀分布在整个原子球体内的"布丁"，电子则像葡萄干一样嵌在其中。这个模型能解释当时已知的许多现象，却对一件小事给出了极其强硬的预言——而正是这个预言被实验推翻了。

汤姆孙模型给出的偏转上限

设原子半径为 R，正电荷 Ze 均匀分布在球内。由高斯定理，球内半径 r 处的电场为

E(r)=k_{e}\frac{Ze\!r}{R^{3}},\ \ E_{\text{max}}=E(R)=\frac{k_{e}Ze}{R^{2}} (1.1)

α 粒子电荷为 2e。取最有利的情形——粒子沿直径穿过、且全程处于最大场强处，横向冲量为

\Delta p_{\perp }\le 2e\cdot E_{\text{max}}\cdot \frac{2R}{v}=\frac{4k_{e}Ze^{2}}{R\!v} (1.2)

入射动量 p = mv，而 mv^{2} = 2E（E 为动能），故单次穿越的最大偏转角为

\theta _{\text{max}}\approx \frac{\Delta p_{\perp }}{p}=\frac{4k_{e}Ze^{2}}{R\cdot mv^{2}}=\frac{2k_{e}Ze^{2}}{R\!E} (1.3)

代入盖革–马斯登实验的实际条件：Z = 79（金）、R \approx 1.0\times 10^{-10} m、E = 5 MeV = 8.01\times 10^{-13} J，得

\theta _{\text{max}}\approx 4.6\times 10^{-4} \text{rad}\approx 0.026^{\circ } (1.4)

也就是说，整个原子的正电荷"摊开"在 10−10 m 尺度上时，它对 α 粒子只能产生百分之几度的扰动。要累积到 90°（1.571 rad），即便假设每次碰撞都恰好取到理论上限、且全部朝同一方向叠加，也至少需要

N\ge \frac{1.571}{4.6\times 10^{-4}}\approx 3.4\times 10^{3} \text{次} (1.5)

而 3400 次独立碰撞全部取向一致的概率量级为 2^{-3400} \approx 10^{-1024}。这是一个极为宽松的上界——真实概率还要小得多。结论无可回避：汤姆孙模型无法产生哪怕一次大角度散射。

这一节说明了什么

式 (1.3) 是纯粹的量纲论证：它只用到"正电荷分布在一个尺度 R 上"这一条。因此它的反面同样成立——只要观察到任意一次大角度散射，就足以断定正电荷不是弥散的，而必定集中在一个远小于 R 的尺度内。这就是 1911 年卢瑟福提出核式模型的全部逻辑起点。

本文的目标与路线

接下来的章节不引用"卢瑟福公式"这一结论，而是从库仑力与两条守恒律出发把它重新推出来，并对每一步的物理含义作出交代。路线是：\S 2 明确假设与其失效尺度 → \S 3 写出力与守恒量 → \S 4 积分轨道方程得到双曲线 → \S 5 用冲量法求出 b-\theta 关系 → \S 6-\S 7 得到最近逼近距离与微分散射截面 → \S 8-\S 9 讨论量级与数值 → \S 10-\S 13 提取推论并划定适用边界。四个附录给出被正文略过的计算细节。

关于 A2 的常见误解

"把原子核当成点电荷"并不意味着核真的没有大小，而是说：在本文所讨论的能量范围内，粒子能靠近的最小距离远大于核半径，因此波函数/轨道从未"进入"核内部，此时点电荷假设是一个可检验的近似。一旦能量高到使 r_{\text{min}} 与核半径可比，这条假设就失效，而它的失效恰恰成为测量核半径的手段（见 \S 10.2）。

几何约定

取靶核为原点，入射方向为 +x 轴。粒子在无穷远处沿一条与 x 轴平行、垂直距离为 b 的直线运动，b 称为瞄准距（impact parameter）。出射方向与原入射方向的夹角 \theta 称为散射角。由于力是中心力，轨道必在一个过原点且含初速度的平面内，以下均在该平面内取极坐标 (r, \varphi )，原点为力心。

三相互作用与守恒律

库仑力与相互作用常数

α 粒子（电荷 ze，z = 2）与靶核（电荷 Ze）同号，相互排斥。取力心为原点，粒子所受的力沿径向朝外：

\vec{F}=\frac{1}{4\pi \varepsilon _{0}}\frac{zZe^{2}}{r^{2}}\hat{r}\equiv \frac{C}{r^{2}}\hat{r} (3.1)

其中把整个相互作用浓缩成了一个常数：

C\equiv k_{e}zZe^{2},\ \ k_{e}\equiv \frac{1}{4\pi \varepsilon _{0}}=8.9875517923\times 10^{9} \text{N}\cdot \text{m}^{2}\text{/C}^{2} (3.2)

C 的量纲是能量×长度（J·m），它同时扮演两个角色：U(r) = C/r 是势能，而 C/E 是一个长度——后文会看到，整个散射问题的所有特征长度都是 C/E 的倍数。相应的势能为

U(r)=\frac{C}{r},\ \ U(\infty )=0 (3.3)

守恒律一：机械能守恒

库仑力是保守力，且只与 r 有关，故机械能守恒。粒子从无穷远处以速度 v_{0} 入射，在无穷远处势能为零：

E=\frac{1}{2}mv_{0}^{2}=\frac{1}{2}mv^{2}+\frac{C}{r}=\text{const} (3.4)

把速度分解为径向与横向两部分 v^{2} = v_{r}^{2} + v_{\varphi }^{2}（其中 v_{\varphi } = r\varphi \dot{}），式 (3.4) 说明：粒子越靠近核，势能越大，可用的径向动能越小——这已经预示了"最近逼近距离"的存在。

守恒律二：角动量守恒

中心力对原点的力矩恒为零，故角动量 \vec{L} = m\vec{r} \times \vec{v} 守恒，方向固定（垂直于轨道平面），大小

L=m\,r^{2}\varphi \dot{} (3.5)

在无穷远处，速度垂直于瞄准距臂，故 L = mv_{0}b。于是式 (3.5) 给出一个后面反复使用的替换关系：

mv_{0}b=m\,r^{2}\varphi \dot{}\ \ \Rightarrow \ \ dt=\frac{m\,r^{2}}{L}d\varphi (3.6)

式 (3.6) 是把"对时间积分"换成"对角度积分"的钥匙。由于被积函数 mr^{2}/L 中含 r^{2}，它恰好能与库仑力的 1/r^{2} 相消——这正是库仑问题能被初等积分求解的深层原因（见附录 B）。

问题的可积性

平面内有 2 个自由度，而式 (3.4) 与 (3.5) 给出 2 个独立守恒量，因此系统完全可积，轨道可由积分封闭求出。定向到具体路径：把式 (3.4) 中的 v^{2} 用 v_{r} = r\dot{} 与 v_{\varphi } = L/(mr) 表出，得到关于 r(t) 的一阶方程；再用式 (3.6) 消去 t，即得轨道方程 r(\varphi )。下一节按这个思路直接给出结果，完整的积分过程放在附录 A。

本节小结

整个散射问题由三个量完全确定：相互作用强度 C、入射能量 E、以及瞄准距 b（隐藏在角动量 L = mv_{0}b 中）。实验中前两者是给定的，b 则是随机的——所以接下来的任务就是找出 b 与可观测的 \theta 之间的确定性关系。
